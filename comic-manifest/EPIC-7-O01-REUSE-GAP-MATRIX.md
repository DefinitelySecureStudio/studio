# Epic 7 O01 — Manifest-to-run reuse/gap matrix

Status: source and contract discovery complete; this is advisory evidence for O01, not approval to run a comic workflow. Source issue: [Studio #102](https://github.com/DefinitelySecureStudio/studio/issues/102); parent: [Epic 7 #101](https://github.com/DefinitelySecureStudio/studio/issues/101).

## Scope recorded before the source/test audit

- **Target:** this single Studio governance file, `comic-manifest/EPIC-7-O01-REUSE-GAP-MATRIX.md`. Studio holds governance; Codex owns normative contracts; Platform owns runtime.
- **Evidence set:** released Prompt SDK v1.0.0; Context Builder v1.0.0 and its immutable Codex contract; unchanged Context Package v1.0.0; Manifest issues #93–#99, release locks and existing tests; Epic 6 and Epic 7 acceptance records; PER-6/PER-7.
- **One bounded path:** public/synthetic approved production-manifest revision → exact prompt and prepared Context Package binding → provider-free Prompt SDK mock execution → offline fake result/artifact verification → separately reviewed reader-safe release proposal. It is a composition of existing reference flows, not an actual comic production build.
- **Finite evidence/test matrix:** (1) exact valid manifest + matching prompt/package/slots/purpose/current authorization; (2) mismatched prompt, package, slot, purpose, classification, revision, or stale/revoked authorization; (3) denied preparation before source read and no implicit refresh/model call; (4) mock execution and provenance handoff; (5) complete/incomplete/tampered/unrelated result against declared outputs; (6) safe/unsafe public projection including private identifiers, paths, hashes, approvals and content-derived fingerprints; (7) revision correction and invalidation of affected approval. Existing checks are named below; missing coverage is called out.
- **Estimate:** 1 focused person-day including source/test review, matrix, document verification and handoff; within issue #102’s 0.5–1 day preliminary estimate and the 2-day execution ceiling.
- **Exclusions:** no orchestration implementation, replacement contracts, workflow DSL, manifest commands, O02+ work, private Lore/source access, production trust integration, spending, art generation, canon promotion, release publication, merge or issue closure. No production-readiness claim from synthetic replay.

Studio main has no tracked `AGENTS.md` or `.agents/skills` instructions. No runtime repository was changed.

## Finding

The existing v1 releases provide reusable boundaries for deterministic preparation, exact package/prompt binding, one mockable provider call, manifest validation, supplied-result verification and a safe release proposal. They do **not** provide a durable multi-step runner. The full synthetic path is supported only by composing separate Builder/SDK and Manifest reference flows; no checked-in command produces a real build result from the manifest or generates rendition bytes.

Use these classifications: **reuse** = existing API/contract covers the behavior; **integration** = a host must compose existing APIs/adapters; **verification** = an API checks supplied evidence but does not create it; **evidenced missing** = v1 explicitly excludes the capability or its API/tests are absent.
