# Support

Use the repository's issue forms for reproducible bugs and scoped feature
proposals. Search existing issues first and include only public, non-sensitive
information needed to understand the request.

This project does not promise individual support, implementation timelines, or
compatibility outside its documented supported versions. Maintainers prioritize
work according to repository responsibility, impact, security, and available
capacity.

Do not use public issues for vulnerabilities, credentials, personal data,
private lore, unreleased material, or confidential communications. Follow
`SECURITY.md` for a private route.
